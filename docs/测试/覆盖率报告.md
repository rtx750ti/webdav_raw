# 生成覆盖率测试

```powershell
cargo install cargo-llvm-cov
cargo llvm-cov --html --output-dir docs/coverage
```

报告入口：`docs/coverage/html/index.html`

# 基础测试

```powershell
cargo test
cargo test --test propfind
```

# 网络测试

需先设置 `WEBDAV_URL`、`WEBDAV_ACCOUNT`、`WEBDAV_PASSWORD`到当前的系统环境当中。

```powershell
cargo test --features network-test -- --ignored --nocapture --test-threads=1
```
